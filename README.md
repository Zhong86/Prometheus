# Prometheus

A research-based AI that aims to get different problems and ideas for software-based solutions. Prometheus gets references from academic studies but also from general public (Google Scholar and Reddit, etc). The agent then synthesizes the results and determine if the software application for the problem is applicable.Finally, a single HTML page can be generated to show what the general system would like.  All this is cross-referenced with previous findings from the database to ensure ideas are new. 

Current Tech Stack: LangFlow, AstraDB, Tavily API, SerpAPI
